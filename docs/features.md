## 体检

点「开始体检」一次查完下面这些，只看不改。查出来的问题里小药箱能修的，集中列在一起，勾上一次修好。

| 检测 | 查什么 |
| --- | --- |
| C 盘剩余空间 | 看看系统盘（一般是 C 盘）还剩多少空间。空间太少，系统更新会失败，软件也可能打不开。 |
| 硬盘健康 | 读取硬盘自己报告的健康状态（SMART），看看硬盘有没有快坏的迹象。 |
| 硬盘读写错误 | 查看系统日志里最近 30 天有没有硬盘坏道、读写失败、文件系统损坏的记录。 |
| 系统时间对不对 | 看看电脑上的日期是不是跳回了过去。时间不对时，几乎所有网站都会报证书错误。 |
| WMI（Windows 管理规范） | 看看 WMI 能不能用。它是软件查电脑信息的接口，坏了以后装软件、玩游戏、打开「系统信息」会报 WMI 错误、「无效类」，小药箱的很多检查也查不了。 |
| 系统是否还在支持期 | 看看你的 Windows 版本微软还管不管。过了支持期就收不到安全更新，中毒、被攻击的风险会变大。 |
| Windows 更新有没有被关掉 | 看看 Windows 更新是不是被「优化」软件或者网上的教程关掉了：更新要用的服务被禁用、被改了登录账户，被策略关掉，或者一暂停就是好几年。 |
| 是否在等待重启 | 看看系统是不是装了更新、正等着重启。没重启之前，更新不算装完，有些问题也修不好。 |
| 最近的崩溃和蓝屏 | 看看最近 7 天有没有程序频繁崩溃、没有响应，或者出现过蓝屏。 |
| 开机用时 | 看看最近一次开机从按下电源到出现桌面，一共花了多久。 |
| Windows 恢复环境 | 看看 Windows 恢复环境（WinRE）有没有开启。系统坏了以后，「重置此电脑」和开机自动修复都要靠它。 |
| Windows 搜索服务 | 看看 Windows 搜索服务有没有被关掉。它给文件建搜索索引，关掉以后在开始菜单、资源管理器里搜文件很慢，很多文件搜不到。 |
| 桌面、文档这些文件夹的位置 | 看看桌面、文档、下载、图片、音乐、视频这几个文件夹指向的位置还在不在。挪到 D 盘或者 OneDrive 以后那边没了，桌面就会一片空白，软件也存不了文件。 |
| 是否是单位管理的电脑 | 看看这台电脑是不是由公司或学校统一管理（加入了域、Entra ID 或 MDM）。单位管理的电脑，很多设置会被自动改回去。 |
| 网络通不通 | 按顺序查网卡、飞行模式、网线和 WiFi、路由器和宽带，看看网络断在哪一环。电脑没网也能查。 |
| 失效的系统代理 | 看看系统代理是不是指向了一个已经不在运行的程序（代理软件、加速器卸载或退出后常见），这可能导致网页打不开。 |
| hosts 文件有没有屏蔽常用网站 | 看看 hosts 文件有没有被改过：屏蔽了杀毒软件、Windows 更新或者常用网站，把网站指到了固定的地址，或者 hosts 文件的位置被改了。某个网站打不开、更新装不上、右下角一直显示「无 Internet」时常是这个原因。 |
| 网络组件（Winsock）有没有被改坏 | 看看所有联网程序都要经过的 Winsock 里，有没有别的软件插进去的网络组件（LSP），有没有文件已经不在的组件。它们出问题时，常见的样子是 QQ、微信能用、网页打不开，或者所有软件都上不了网。 |
| 浏览器快捷方式有没有被加网址 | 看看桌面、开始菜单、任务栏上浏览器的快捷方式后面有没有被加上网址。被加了的，一打开浏览器就先打开那个网址（常见的是 2345、hao123 这类导航网站），在浏览器的设置里怎么改主页都没用。 |
| 用户账户控制（UAC） | 看看用户账户控制有没有被关掉。它开着时，软件要改系统、装驱动之前，Windows 会先弹出来问你一下，病毒就不能不声不响地改系统。 |
| Windows 防火墙 | 看看 Windows 防火墙有没有被关掉。连在酒店、咖啡店、学校这些公共 WiFi 上时，防火墙挡着同一个网络里别的电脑直接连进来。 |
| 程序被「劫持」（映像劫持） | 看看任务管理器、注册表编辑器、杀毒软件和登录界面上的「粘滞键」这些程序，有没有被偷偷换成别的程序。病毒常这么做：让人打不开任务管理器和杀毒软件，或者在登录界面留一个后门。 |
| 被停用的系统工具 | 看看任务管理器、注册表编辑器、命令提示符、「运行」、控制面板、右键菜单、关机按钮这些，有没有被策略停用。病毒和「锁机」软件常这么做，让人没法查、没法关掉它。 |
| BitLocker 加密 | 看看硬盘有没有开启 BitLocker 加密（Windows 11 24H2 起很多新电脑会自动开启）。开了加密，重装系统、换主板之前一定要先备份恢复密钥。 |
| 安全启动证书（2023 版） | 看看安全启动有没有开启，以及主板里的安全启动证书有没有更新到微软 2023 年的新证书。 |
| TPM 安全芯片 | 看看电脑有没有 TPM 2.0 安全芯片。Windows 11 需要它，BitLocker 加密用它也更方便。 |
| 设备和驱动 | 看看设备管理器里有没有没装驱动、出了问题的设备。刚重装完系统时，网卡、显卡常常还没有驱动。 |
| 屏幕分辨率 | 看看每个显示器用的是不是它推荐的分辨率。不是推荐的分辨率时画面要拉伸，字和图标会发虚。 |
| 键盘、鼠标、光驱这些设备的驱动登记 | 看看键盘、鼠标、光驱、USB、摄像头这几类设备的「过滤驱动」列表里，有没有已经卸载了的软件留下的名字。有的话，这一类设备全都用不了，设备管理器里显示代码 19、39。 |
| 系统盘类型 | 看看系统装在固态硬盘还是机械硬盘上。系统装在机械硬盘上，开机和打开软件都会明显慢一些。 |
| 内存大小 | 看看内存有多大、还有没有空的内存插槽。内存只有 4 GB 的电脑，现在用起来会很卡。 |
| 虚拟内存 | 看看虚拟内存（分页文件）是不是被关掉了。关掉以后，开大型游戏、PS、剪辑软件时容易提示「内存不足」、闪退，蓝屏了也记不下原因。 |
| 显卡：集成显卡和独立显卡 | 看看这台电脑有没有独立显卡、独立显卡能不能用，台式机的显示器是不是插在了主板上（这样玩游戏用不上独立显卡）。 |
| 电池健康 | 看看笔记本电池老化了多少：现在充满电的容量，和出厂时的设计容量相比还剩多少。 |
| CPU 是否支持新版 Windows 11 | 看看 CPU 支不支持 Windows 11 24H2 起必需的 POPCNT 和 SSE4.2 指令。 |

## 按症状修

在「按症状修」里搜大白话或者错误代码。每个症状一步步查原因：能修的给修复按钮，要自己动手的给图文步骤，修不了的说清楚下一步找谁。

### 上网和共享（8 个）

| 症状 | 说明 | 怎么修 |
| --- | --- | --- |
| 共享文件夹打不开、看不到别的电脑 | 打开别的电脑、NAS、路由器上的共享文件夹时提示「找不到网络路径」（0x80070035）、「未指定的错误」（0x80004005）、「你不能访问此共享文件夹」；或者「网络」里看不到别的电脑，别人也看不到这台。 | 半自动 |
| 电脑开不了移动热点，手机连不上 | 想让电脑开个热点给手机用，打开「移动热点」提示「我们无法设置移动热点」；或者开了以后手机搜不到、连上了却上不了网。 | 半自动 |
| WiFi、网线隔一会儿就断 | 网络用着用着就断开，过一会儿又自己连上；或者电脑睡眠、合上盖子再打开以后连不上网，要重启才好。 | 半自动 |
| 上不了网 | 网页打不开、微信能用但浏览器不行、Wi-Fi 连上了却没网。 | 半自动 |
| 显示「无 Internet」，其实能上网 | 任务栏右下角的网络图标变成小地球或者带黄色感叹号，说「无 Internet」「无网络访问」，可网页明明能打开；Office、应用商店、微软账户也说没联网。 | 半自动 |
| 远程桌面连不上 | 用 Windows 自带的「远程桌面连接」连不上别的电脑，或者别的电脑连不进这台电脑；提示「你的凭据不工作」「出现身份验证错误」「CredSSP 加密数据库修正」「无法连接到远程计算机」；不知道远程桌面怎么打开。 | 半自动 |
| WiFi 不见了、飞行模式关不掉 | 任务栏右下角、设置里找不到 WiFi，搜不到任何无线网络，只剩有线网络；或者飞行模式的按钮是灰的、关不掉。 | 半自动 |
| WiFi 信号差、网速慢 | WiFi 只有一两格信号，网页打开慢、视频卡、下载慢；离路由器远一点就不行；Windows 提示这个 WiFi「不安全」「使用较旧的安全标准」。 | 半自动 |

| 启用或关闭 Windows 功能 | 打开「启用或关闭 Windows 功能」：老软件提示需要 .NET Framework 3.5 时，在这里勾上「.NET Framework 3.5（包括 .NET 2.0 和 3.0）」，点「确定」，Windows 会自己下载装好。 |

## 全部检测

### 网络（18 项）

| 检测 | 查什么 |
| --- | --- |
| 网卡的省电设置 | 看看网卡有没有勾「允许计算机关闭此设备以节约电源」。勾着时，有的 WiFi、有线网卡会时不时掉线，或者睡眠醒来以后连不上网。 |
| 飞行模式 | 看看「飞行模式」是不是开着。开着的时候 WiFi、蓝牙都会被关掉。 |
| 网络通不通 | 按顺序查网卡、飞行模式、网线和 WiFi、路由器和宽带，看看网络断在哪一环。电脑没网也能查。 |
| 查网站地址（DNS） | 看看电脑能不能通过 DNS 查到常用网站的地址。查不到时，网页都打不开，微信、QQ 这类软件却可能还能用。 |
| hosts 文件有没有屏蔽常用网站 | 看看 hosts 文件有没有被改过：屏蔽了杀毒软件、Windows 更新或者常用网站，把网站指到了固定的地址，或者 hosts 文件的位置被改了。某个网站打不开、更新装不上、右下角一直显示「无 Internet」时常是这个原因。 |
| 移动热点用到的服务 | 看看电脑开移动热点要用的两个系统服务有没有被「优化」软件关掉。关掉以后打开移动热点会提示「我们无法设置移动热点」。 |

| 鼠标的设置 | 看看鼠标的左右键有没有被互换、滚轮是不是被设成不滚、有没有开着「单击锁定」「指针轨迹」「自动跳到默认按钮」，双击速度、指针速度是不是调得太偏。 |
| 系统盘类型 | 看看系统装在固态硬盘还是机械硬盘上。系统装在机械硬盘上，开机和打开软件都会明显慢一些。 |
| U 盘驱动 | 看看 U 盘驱动（USB 大容量存储）有没有被禁用。被禁用以后，大部分 U 盘、读卡器、移动硬盘插上都没反应。 |
| U 盘设置和插着的 U 盘 | 看看有没有让 U 盘看不到、没有盘符、存不进去的设置，再看看插着的 U 盘、移动硬盘有没有分到盘符。先把 U 盘插上再查。 |
| USB 选择性暂停 | 看看电源计划里的「USB 选择性暂停」开着没有。开着时 Windows 会暂停一会儿没动的 USB 设备来省电，有的鼠标、键盘、U 盘醒不过来，就会卡顿、断开。 |
| CPU 虚拟化（VT） | 看看处理器的虚拟化（常说的 VT）开没开。安卓模拟器、虚拟机、WSL 2 都要用它，没开时模拟器会很卡或者打不开，要在 BIOS 里打开。 |
