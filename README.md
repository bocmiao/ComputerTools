# 电脑小药箱（暂定名）

[![CI](https://github.com/bocmiao/ComputerTools/actions/workflows/ci.yml/badge.svg?branch=main)](https://github.com/bocmiao/ComputerTools/actions/workflows/ci.yml)

免费、开源的 Windows 工具箱，兼顾日常文件与文本处理、电脑诊断和故障修复。

- 普通人可以按症状点「上不了网」「C 盘满了」「打印机连不上」，自己查出原因、修好电脑。
- 日常工具可以在本机处理文件和文字，例如校验下载文件、整理 JSON、转换文本编码。
- 帮亲友修电脑的「懂哥」可以装在 U 盘里带着走，批量处理。

> **项目处于早期开发阶段，诊断和修复工具仍在验证，还不适合普通用户使用。** 名称还是暂定的，见[计划书第十三节](docs/plan.md#十三待拍板的事项附建议)。

## 现在能做什么

- **体检**：只看不改，查 C 盘空间、硬盘健康、系统时间、系统支持期、Windows 更新有没有被关掉、网络通不通、失效的代理、hosts 文件有没有屏蔽常用网站和 Windows 更新、没装驱动的设备、恢复环境有没有开、浏览器快捷方式后面有没有被加上网址、虚拟内存、Windows 搜索服务、用户账户控制（UAC）和防火墙有没有被关掉等 27 项，没问题就说一切正常；查出来的问题里小药箱能修的（比如恢复环境被关了、代理失效了、浏览器快捷方式被加了 2345 这类网址、虚拟内存、Windows 搜索服务被「优化」软件关掉了），集中列在一起，勾上一次修好，都能撤销。
- **按症状修**：上不了网（按网卡、路由器、宽带、DNS、hosts 文件、代理、系统时间的顺序查；hosts 里屏蔽、改指了常用网站的那几行能一键删掉，别的记录不动）、C 盘满了（台式机能一键缩小休眠文件）、开机慢、共享打印机连不上、打印机显示脱机（被勾上「脱机使用打印机」「暂停打印」的一键恢复，网络打印机 IP 变了、SNMP 更新重启的）、浏览器主页被改了（一打开就是 2345、hao123：快捷方式后面被加的网址一键去掉，只去掉网址，能撤销）、搜不到文件（Windows 搜索服务被关掉了能一键恢复，索引没建好、坏了的教你重建）、桌面图标不见了（「显示桌面图标」没勾上的一键勾回来；桌面、文档、下载指向的移动硬盘、D 盘、OneDrive 没了、提示「位置不可用」的，一键改回默认位置，不搬文件、能撤销；文件跑到 就停的说清楚是厂商的电池养护功能、在哪关，充电器功率不够、没认出充电器的教你怎么办，看哪个软件最费电）、「此电脑」右键「管理」和任务栏图标打不开（按「去掉快捷方式小箭头」教程删掉的系统标记一键加回来，能撤销）、开机黑屏只有鼠标（被病毒、锁机软件换掉的「外壳」和登录程序查得出来，一键改回 Windows + P、显示器输入源、闪屏是驱动还是软件、Win + Ctrl + Shift + B 重启显卡驱动，一步步教）、共享文件夹打不开和局域网里看不到别的电脑（0x80070035：网络被当成「公用网络」的一键改成专用，共享用的服务被关掉的一键恢复，都能撤销；防火墙没放行、「永恒之蓝」时关掉的 445 端口、只支持 SMB1 的老 NAS、只让来宾进的共享，说清楚在哪改、为什么不建议降低安全设置；输对方电脑的账户密码、清掉记错的凭据这些常见的坑写成步骤）、右下角显示「无 Internet」其实能上网（Windows 的联网检测被「优化」软件、网上的教程关掉或改掉的，一键改回微软的默认设置，能撤销；代理软件、加速器留下的代理一起查；被组策略关掉的说清楚在哪改）、WiFi 不见了和飞行模式关不掉（WiFi - **常用设置**：显示扩展名、经典右键菜单、关掉开始菜单和锁屏里的推荐广告、不再自动装推荐的应用、任务栏按钮不合并、时钟显示秒、关闭鼠标加速、关闭快速启动、找回 Windows 照片查看器（看图快，图片的类型和图标不变）、打开剪贴板历史（Win + V）、连按 Shift 不再弹出粘滞键、微软拼音改成按 Ctrl 切换中英文、桌面显示「控制面板」、不记录最近打开的文件等 27 项，改之前预览，改完能撤销；右键菜单里软件加的项目（压缩、网盘、编辑器这些）不常用的可以拿掉；右键「新建」里的项目（新建 WPS 文档、思维导图、BMP 图像、联系人这些）不用的也可以关掉；资源管理器左边导航栏和「此电脑」里软件加的图标（WPS 云文档、百度网盘、OneDrive 这些）不用的可以隐藏，都随时能恢复。
- **工具箱**：本地文件校验（MD5、SHA-1、SHA-256，自动认出官方给的是哪一种）、文本整理（全角半角、去空行去重、排序、数字数）、屏幕坏点、键盘、鼠标、喇叭左右声道、麦克风和摄像头测试、硬盘测速（顺序读写和 4K 随机读，看是不是固态、有没有慢得不正常；验机用）、别让电脑自己睡着（下载、上网课时用，关掉就恢复）、定时关机和定时重启（多久以后或者到几点，随时能取消）、文件删不掉时看是哪个程序占着（只查不改）、弹窗是哪个软件的（鼠标移到弹窗上停几秒，看是哪个程序弹的、属于哪个已安装的软件，只查不改）、找大文件和内容完全一样的重复文件（只查不删）、U 盘里的文件不见了、变成快捷方式时把被病毒藏起来的文件显示回来（病毒程序照样藏着，能改回去）、批量重命名（查找替换、序号、前后缀、改扩展名，能撤销）、图片批量压缩和转格式（改尺寸、压到多少 KB 以内、证件照尺寸、给身份证复印件加「仅用于办理 XX」的水印，原图不动）、图片合成 PDF（拍的证件、合同、作业照片按顺序合成一个 PDF，能调顺序、转方向，A4 纸或者和图片一样的比例）、长图拼接（几张聊天记录、网页截图上下拼成一张长图或者左右并排，能直接粘贴截图，拼好能复制了发微信）、图片隐私清理、文字和网址变二维码（电脑上的网址、取件码发到手机上）、金额和日期转大写（写支票、发票、借条用，照人民银行的规定）、文本对比（合同、通知改过以后看改了哪里，改过的行里不一样的字标出来）、日期计算（相差几天、几年几个月、中间几个工作日，往后推多少天或多少个工作日是哪天）、JSON 格式化与校验、URL/Base64 文本转换；也能查看 C 盘被什么占了、最近的蓝屏（每种终止代码的原因和办法）、谁把电脑叫醒的（最近几次醒来的原因、能叫醒电脑的设备和计划任务）、开关机记录（最近 7 天每天几点开机、关机、重启、睡眠、醒来，关机是开始菜单、Windows 更新还是关机命令发起的，有没有断电、死机、蓝屏、长按电源键）、开机慢在哪（最近是哪个软件、驱动、服务、设备拖慢了开机和关机）、U 盘弹不出是谁占着、装了哪些程序（最近装的、卸载程序不见了的、最占地方的）、电脑配置、能不能升级 Windows 11、WiFi 密码（还能显示二维码，手机一扫就连上）和 BitLocker 恢复密钥（重装前抄下来），刷新 DNS、重启资源管理器和打印服务、清空卡住的打印队列、让打印机恢复工作（取消「脱机使用」「暂停打印」）、重建图标和缩略图缓存（图标变白、显示成别的图标时用）、重置更新组件（下载坏了的更新缓存改名留着，不删除）、检查并修复系统文件（依次运行 Windows 自带的 DISM 和 SFC）、安装微软 VC++ 运行库（从微软官网下载最新版，32 位和 64 位都装，已经装着的不重复装）、创建还原点（装驱动、装软件、改设置之前建一个，出了问题能退回来；刚建过也能再建，系统保护没开的教你打开）、安装 .NET Framework 3.5（老软件要用；装不上的说清楚是没联网、更新服务被关了，还是「关更新」软件改了更新服务器）、打开 DirectPlay（老游戏要用）、远程求助（打开 Windows 自带的「快速助手」，打开前先把反诈提示说清楚：只让认识、信得过的人连）、重置应用商店缓存，或打开 Windows 自带工具（任务管理器、设备管理器、「启用或关闭 Windows 功能」、电池使用情况这些）。
- **修改日志**：每一处改动都记下来，可以逐条或整次恢复原状。
- **诊断报告**：去掉隐私信息的纯文本报告，可以写上遇到了什么问题，复制发给懂哥，或者复制给豆包、DeepSeek 这些 AI 问问（小药箱自己不连任何 AI）。

## 原则

1. **先诊断，后动手**：先说清楚哪里有问题，征得同意再改。
2. **能撤销**：每一项修改都记进修改日志，可以逐项撤销；不能撤销的，事先用红字说明。
3. **说人话**：每个功能都用一句大白话说明「会做什么、有什么影响」。
4. **零打扰**：没有广告、捆绑、遥测和账号；不改浏览器主页，不开机自启，不常驻后台。
5. **可验证**：源码公开、构建过程公开、安装包带签名、官网公布校验值。
6. **只用系统自带或官方来源**。
7. **不制造焦虑**：没问题就说「一切正常」，不打分。
8. **知道边界**：修不了的问题直接说明，并告诉你下一步该找谁。
9. **用户文件零容忍**：凡是会删除你的文件的操作，都逐项确认，默认不勾选。
10. **优先用系统自己的机制**：即使卸载了小药箱，改过的设置在系统里也看得到、改得回。

## 我们不做什么

我们不做以下这些，每一条的原因都写在[计划书第五节](docs/plan.md#五我们不做什么以及为什么)：

- 激活工具
- 广告和捆绑
- 遥测
- 关闭 Defender
- 永久禁用更新
- 精简或删除系统组件
- 第三方修改版系统镜像
- 驱动库
- 杀毒
- 「一键加速」
- 关闭 UAC 或 SmartScreen
- 用 hosts 屏蔽微软
- 远程控制

## 开发

需要：[Rust](https://rustup.rs/)（版本由 `rust-toolchain.toml` 固定）、Node.js 24 和 pnpm（`corepack enable`）。打包安装包需要在 Windows 上进行。

```sh
cargo test                              # 引擎测试；装了 pwsh 时还会跑脚本宿主协议测试
cargo run -p medkit-data -- check       # 校验 catalog/ 和 scripts/
pnpm install
pnpm --dir app dev                      # 在浏览器里开发界面（用示例数据，不碰系统）
pnpm tauri dev                          # Windows 上真实运行：要在「以管理员身份运行」的终端里执行
pnpm tauri build                        # Windows 上：生成安装包
```

每次推送到 `main`，CI 都会在 Windows 上构建安装包和便携版。在 [Actions](https://github.com/bocmiao/ComputerTools/actions/workflows/ci.yml) 页面打开最新一次运行，下载 `medkit-windows-x64` 即可（未签名，只供测试）。

目录结构：

| 目录 | 内容 |
| --- | --- |
| `catalog/` | 检测、修复、症状、检测清单（YAML） |
| `scripts/` | PowerShell 脚本（只用 ASCII，兼容 Windows PowerShell 5.1） |
| `crates/medkit-core/` | 引擎：数据校验、执行、修改日志与撤销、脚本宿主 |
| `crates/medkit-data/` | 数据工具：校验、生成 JSON Schema、打包 |
| `src-tauri/` | 桌面外壳 |
| `app/` | 界面（Vue 3） |
