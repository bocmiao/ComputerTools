# 电脑小药箱（暂定名）

[![CI](https://github.com/bocmiao/ComputerTools/actions/workflows/ci.yml/badge.svg?branch=main)](https://github.com/bocmiao/ComputerTools/actions/workflows/ci.yml)

免费、开源的 Windows 工具箱：按症状查问题、修电脑，也有日常处理文字、图片和文件的小工具。

- **普通人**：按症状点「上不了网」「C 盘满了」「打印机连不上」，自己查出原因、修好电脑。
- **帮亲友修电脑的「懂哥」**：装在 U 盘里带着走，诊断报告一键复制。
- **日常**：校验下载的文件、压缩图片、批量重命名、图片转文字，都在本机处理，不上传。

> **项目处于早期开发阶段，诊断和修复还在真机验证，暂时只适合测试。** 名称还是暂定的，见[计划书第十三节](docs/plan.md#十三待拍板的事项附建议)。

## 下载试用

- 在 [Releases](https://github.com/bocmiao/ComputerTools/releases) 下载最新的预览版：`medkit-…-setup.exe` 是安装版，`medkit-…-portable.exe` 是便携版（不用安装，直接运行）。
- 要求：64 位的 Windows 10 或 Windows 11。小药箱启动时会请求管理员权限。
- 还没有代码签名，Windows 会提示「Windows 已保护你的电脑」：点「更多信息」→「仍要运行」。
- 建议先在虚拟机或者不要紧的电脑上试。改设置之前都会先预览，改完能在「修改日志」里撤销；不能撤销的会事先说明。

### 常见症状

| 类别 | 例子 |
| --- | --- |
| 上网和共享 | 上不了网、显示「无 Internet」其实能上网、WiFi 老断、共享文件夹打不开、远程桌面连不上 |
| 开机和系统 | 开机慢、蓝屏自己重启、电脑卡、更新失败、开机黑屏只有鼠标、临时配置文件登录 |
| 软件和浏览器 | 闪退、缺少 dll、「此应用无法在你的电脑上运行」、Office 和 Edge 打不开、浏览器主页被改、老弹广告 |
| 文件和 C 盘 | C 盘满了、误删文件、文件删不掉、回收站已损坏、搜不到文件 |
| 打印机 | 连不上、显示脱机、0x0000011b、0x00000709 |
| 屏幕、键盘和设备 | 屏幕变黑白、字发虚、没声音、麦克风和摄像头用不了、蓝牙、U 盘、快捷键没反应 |

弹出了报错窗口的，把截图粘贴进来，小药箱用 Windows 自带的文字识别认出上面的字，找到对应的症状（不联网）。

### 工具箱

都在本机处理，不上传。

| 类别 | 工具 |
| --- | --- |
| 文字 | 文件校验（MD5、SHA-1、SHA-256）、文本整理、JSON 格式化与校验、文本编码转换、文本对比、文字和网址变二维码、金额和日期转大写、日期计算 |
| 图片 | 批量压缩、转格式、改尺寸、加水印；图片合成 PDF；长图拼接；图片转文字；图片隐私清理 |
| 文件 | 批量重命名、文件删不掉时看是谁占着、弹窗是哪个软件的、找大文件和重复文件、微信占的地方、U 盘里的文件不见了 |
| 测试和控制 | 屏幕坏点、键盘、鼠标、喇叭、麦克风、摄像头测试；硬盘测速；别让电脑自己睡着；显示器亮度；定时关机和定时重启 |

### 其他

- **右键菜单和资源管理器**：软件加的右键项目、右键「新建」里的项目、资源管理器里多出来的图标，不用的能关、随时能恢复；老是误按的键能关掉，坏了的键能换成别的键（改键）。
- **开机启动项**：列出开机自己启动的软件，能停用、能恢复，和任务管理器里是同一个开关。
- **修改日志**：每一处改动都记下来，可以逐条或者整次恢复原状。
- **诊断报告**：去掉隐私信息的纯文本报告，可以写上遇到了什么问题，复制发给懂哥，或者复制给豆包、DeepSeek 这些 AI 问问（小药箱自己不连任何 AI）。

## 原则

1. **先诊断，后动手**：先说清楚哪里有问题，征得同意再改。
2. **能撤销**：每一项修改都记进修改日志，可以逐项撤销；不能撤销的，事先用红字说明。
3. **说人话**：每个功能都用一句大白话说明「会做什么、有什么影响」。
4. **零打扰**：没有广告、捆绑、遥测和账号；不改浏览器主页，不开机自启，不常驻后台。
5. **可验证**：源码公开、构建过程公开、安装包带签名、官网公布校验值。
6. **只用系统自带或官方来源**。
7. **不制造焦虑**：没问题就说「一切正常」，不打分。
8. **知道边界**：修不了的问题直接说明，并告诉你下一步该找谁。
9. **用户文件零容忍**：凡是会删除你的文件的操作，都逐项确认，默认不勾选。
10. **优先用系统自己的机制**：即使卸载了小药箱，改过的设置在系统里也看得到、改得回。

## 我们不做什么

我们不做以下这些，每一条的原因都写在[计划书第五节](docs/plan.md#五我们不做什么以及为什么)：

- 激活工具
- 广告和捆绑
- 遥测
- 关闭 Defender
- 永久禁用更新
- 精简或删除系统组件
- 第三方修改版系统镜像
- 驱动库
- 杀毒
- 「一键加速」
- 关闭 UAC 或 SmartScreen
- 用 hosts 屏蔽微软
- 远程控制

## 开发

需要：[Rust](https://rustup.rs/)（版本由 `rust-toolchain.toml` 固定）、Node.js 24 和 pnpm（`corepack enable`）。打包安装包需要在 Windows 上进行。

```sh
cargo test                              # 引擎测试；装了 pwsh 时还会跑脚本宿主协议测试
cargo run -p medkit-data -- check       # 校验 catalog/ 和 scripts/
cargo run -p medkit-data -- features    # 加了检测、症状、功能、小工具以后，更新功能清单
pnpm install
pnpm --dir app dev                      # 在浏览器里开发界面（用示例数据，不碰系统）
pnpm tauri dev                          # Windows 上真实运行：要在「以管理员身份运行」的终端里执行
pnpm tauri build                        # Windows 上：生成安装包
```

每次推送到 `main`，CI 都会在 Windows 上构建安装包和便携版：在 [Actions](https://github.com/bocmiao/ComputerTools/actions/workflows/ci.yml) 页面打开最新一次运行，下载 `medkit-windows-x64`（未签名，只供测试）。推送 `v` 开头的标签（比如 `v0.0.1`）时，所有检查都通过以后会自动发布到 Releases（预览版）。

目录结构：

| 目录 | 内容 |
| --- | --- |
| `catalog/` | 检测、修复和常用设置、症状、小工具、检测清单（YAML） |
| `scripts/` | PowerShell 脚本（只用 ASCII，兼容 Windows PowerShell 5.1） |
| `crates/medkit-core/` | 引擎：数据校验、执行、修改日志与撤销、脚本宿主 |
| `crates/medkit-data/` | 数据工具：校验、生成 JSON Schema 和功能清单、打包 |
| `src-tauri/` | 桌面外壳 |
| `app/` | 界面（Vue 3） |
